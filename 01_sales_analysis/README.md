# Анализ продаж

## Цель
Показать базовый процесс анализа табличных данных: загрузка, проверка качества, вычисление метрик, группировка и визуализация.

## Данные
`data/sales.csv` — синтетический набор данных о заказах за 2025 год. Данные созданы для проекта и не относятся к реальной компании.

## Что делает скрипт
- проверяет наличие обязательных полей и некорректных значений;
- рассчитывает выручку для каждой строки;
- агрегирует выручку по месяцам, категориям и регионам;
- выводит общую выручку, среднюю выручку на заказ и наиболее доходный товар;
- сохраняет CSV-таблицы и PNG-графики в папку `output`.

## Запуск
Из корня репозитория:
```bash
pip install -r requirements.txt
python 01_sales_analysis/analyze_sales.py
```
## Результаты работы

Скрипт обрабатывает 120 записей о продажах и формирует сводные таблицы и графики.

Пример результатов:
- Общая выручка: 31 452
- Средняя выручка на заказ: 262,10
- Товар с наибольшей выручкой: Monitor
- Наибольшая выручка по категории: Electronics — 23 130

## Создаваемые файлы

В папке `output` сохраняются:

- `monthly_revenue.csv` — выручка по месяцам;
- `revenue_by_category.csv` — выручка по категориям;
- `revenue_by_region.csv` — выручка по регионам;
- `monthly_revenue.png` — график выручки по месяцам;
- `revenue_by_category.png` — график выручки по категориям.

## Используемые технологии

Python, Pandas, NumPy, Matplotlib, pathlib.
