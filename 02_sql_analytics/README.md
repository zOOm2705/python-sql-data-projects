# SQL Analytics: аналитика продаж

## Цель
Продемонстрировать проектирование простой реляционной схемы и использование SQL для аналитических запросов.

## Состав
- `schema.sql` — создание таблиц, ограничения целостности и тестовые данные;
- `queries.sql` — аналитические запросы с `JOIN`, `GROUP BY`, CTE и оконными функциями `SUM() OVER`, `LAG()` и `DENSE_RANK()`.

## Как запустить
1. Откройте SQLite или DB Browser for SQLite.
2. Выполните весь файл `schema.sql`.
3. Выполняйте запросы из `queries.sql` по отдельности.

Данные синтетические и предназначены только для демонстрации SQL.
